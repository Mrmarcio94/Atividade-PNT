# Feira do Porto
Sistema web de pedidos de itens de pescados e hortifruti. O cliente faz o pedido pelo PC e vai à mercearia retirar o produto.

## Funcionalidades
- Cadastro e login de cliente

## Tecnologias utilizadas
- PHP 8.2
- MySQL 8
- HTML, CSS e JavaScript
- XAMPP (ambiente local)


## Como rodar
1. Instale o XAMPP e ligue Apache e MySQL.
2. Copie a pasta `database` para `C:\xampp\htdocs`.
3. No phpMyAdmin, importe `database/feira-do-porto.sql`.
4. Acesse http://localhost/feira-do-porto
Passos detalhados em `docs/instalacao.md`.
